# 飲酒の量・頻度と生活満足度：単純な回帰とsurveyを比較する設計書

更新日：2026-10-10（日本時間）／設計版：2.0

状態：設計2.0のデータ精査・クリーニング、通常の回帰、surveyによる推定・比較・検証まで完了。共通対象は255,168人（過去30日に飲酒なし123,182人、飲酒者131,986人）。対象・カテゴリ・式・不確実性の計算方法は変更していない。旧版1.3のデータ・コード・記録は保持し、旧版の111,202人を新版の対象とは扱わない。通常の回帰は[ステップ2報告](ordinary-regression-report-v2.md)、surveyとの比較は[ステップ3報告](survey-comparison-report-v2.md)に保存した。記事作成は未着手。

## 1. 分析する問い

> 飲酒の頻度、飲酒日の平均量が異なる人たちでは、生活への不満の割合がどの程度違うか。その推定値と信頼区間は、通常のRの回帰とsurveyでどう違うか。

量と頻度をそれぞれ1つの説明変数として使い、年齢・性別・所得などは主分析で調整しない。「単回帰」は、ここでは説明変数を1つにしたロジスティック回帰を指す。カテゴリ変数の水準に対応する複数の係数は使うが、別の背景変数は追加しない。

対象には、過去30日に飲酒しなかった人も含める。評価項目は生活満足度だけとする。個人の飲酒行動を変えた前後を追うデータではないため、「どう変わったか」は「群によってどう違うか」と表現する。

## 2. 2つの単純なモデル

| モデル | 説明変数 | 比較する分類 |
| --- | --- | --- |
| 頻度モデル | 過去30日の飲酒日数のカテゴリ | 飲酒なし、1〜3日、3日超〜7日、7日超〜15日、15日超〜30日 |
| 量モデル | 飲酒日の平均ドリンク数のカテゴリ | 過去30日に飲酒なし、飲酒日に平均1、2、3〜4、5以上のドリンク |

各モデルを通常の`glm`と`survey::svyglm`で計算する。量と頻度を同じモデルに入れず、背景変数も主分析では調整しない。各指標を別々の軸で見せるための2モデルであり、2つの独立した因果効果を推定する設計ではない。

カテゴリの境界は結果を見る前の表示上の区切りであり、安全・危険の基準とは扱わない。量・頻度が増えれば必ず不満が増えるという直線関係も仮定しない。結果に合わせて境界を選び直さない。

### 2.1 評価項目

`LSATISFY`の1=非常に満足、2=満足をY=0、3=不満、4=非常に不満をY=1とする。7・9・空欄は欠測とする。主に示すのは生活への不満の割合で、生活満足度を点数として平均しない。4段階の元回答も保持する。

### 2.2 頻度の定義

`ALCDAY4`の101〜107は週の日数×30/7、201〜230は月の日数に変換し、30日当たりの日数Dを求める。週回答は小数のまま扱い、分類前に丸めない。

- 888：過去30日に飲酒なし。整合する回答ではD=0とする。
- 777・999・空欄：頻度不明。0日とは扱わない。
- 飲酒者の有効範囲：週1〜7日、月1〜30日。

頻度カテゴリはD=0、0<D≤3、3<D≤7、7<D≤15、15<D≤30の順に固定する。D=0を回帰の参照カテゴリにする。

### 2.3 量の定義

`AVEDRNK3`は、過去30日の**飲酒日に平均して何ドリンク飲んだか**という質問である。1回の飲酒機会の量や、飲まない日も含む1日平均とは区別する。[CDC公式質問票、Core Section 12](https://www.cdc.gov/brfss/questionnaires/pdf-ques/2023-BRFSS-Questionnaire-508.pdf#page=40)

現在飲酒者の1〜76を有効な平均量Aとし、1、2、3〜4、5〜76の4カテゴリにする。77・99・空欄は量の欠測とする。大きな有効値を結果に応じて切り落としたり、上限を置き換えたりしない。

`ALCDAY4=888`の人は、量モデルでも「過去30日に飲酒なし」という独立した参照カテゴリにする。この場合のAVEDRNK3の空欄は正常な質問スキップであり、量の欠測を理由に除外しない。飲酒日の平均量は定義できないため、Aに0を補完せず、カテゴリとして非飲酒を表現する。

有効な正の飲酒日数があるのに`AVEDRNK3=88`（None）となる回答は量の分類を保留し、主分析の共通対象から除いて件数を記録する。頻度不明の人をAVEDRNK3=88だけで非飲酒者に振り分けない。

ドリンクはBRFSSの質問票上の単位であり、日本のグラス数・日本酒の合数へそのまま置き換えない。量モデルが示すのは飲酒日の平均量との関連であり、30日間の総摂取量との関連ではない。

## 3. 対象者と新版クリーニング

生活満足度モジュールの39州とDC、43の州・質問票版の採用元は変更しない。18歳以上の成人で、次の条件を満たす共通の対象者Sを作る。

1. 重み・層・PSUが有効で、生活満足度の回答が1〜4である。
2. 飲酒頻度が有効に分類できる。
3. 現在飲酒者はAVEDRNK3が1〜76である。過去30日に飲酒なしの人には量の回答を要求しない。
4. 飲酒なしと正の量・多量飲酒回数などが同時に記録される、明確に整合しない回答は分類保留とする。

頻度モデルと量モデルを同じ人たちについて比較するため、Sは両指標が定義できる共通集合とする。頻度は分かるが量が欠測の飲酒者も、共通集合から除く理由と人数を示す。年齢・性別・所得などの欠測や、飲酒者の多量飲酒回数の欠測を主分析の除外条件にしない。

元の全303,632件は保持し、新しい頻度・量カテゴリ、解析対象フラグ、除外理由を作る。元回答の補完は行わない。重複点検のキーは_STATEとSEQNOとする。

`scripts/07_profile_redesign.R`で収録状況を点検した。

- AVEDRNK3、MAXDRNKS、_DRNKWK2は4ファイルにあり、全版別回答者を主ファイルに照合した値が一致した。
- 現在飲酒者147,508人のうち、AVEDRNK3が1〜76の人は144,997人。88の回答は500人、その他の不明・拒否・空欄は2,011人だった。
- 飲酒なしと正の量・最大量・多量飲酒回数が同時に記録された例は0件だった。
- 利用可能性の点検で候補だった255,168人を、新版のクリーニングと別プロセスでの検証により共通対象Sとして確定した。飲酒なし123,182人、飲酒者131,986人を含む。
- 全303,632件のうち、頻度不明21,506人、飲酒日数あり・量88の分類保留500人、飲酒者の量欠測2,011人、残った対象で生活満足度が欠測の24,447人を、この順に除外した。重み・設計情報・年齢による除外と明確な飲酒回答の不整合は0件だった。
- 背景項目に欠測のある48,795人、多量飲酒回数が欠測の飲酒者1,209人も、生活満足度・量・頻度が有効ならSに含む。人数には重なりがある。
- 頻度の5カテゴリの人数は、飲酒なし123,182、1〜3日45,291、3日超〜7日29,652、7日超〜15日28,989、15日超〜30日28,054。
- 量の5カテゴリの人数は、飲酒なし123,182、平均1ドリンク60,207、2ドリンク40,404、3〜4ドリンク21,763、5以上9,612。

元の項目点検は`outputs/redesign_sample_availability.csv`、`redesign_quantity_codes.csv`、`redesign_source_comparison.csv`に保存。新版の確定データは`data/processed/v2/`、除外・分類・142項目の検証記録は`outputs/v2/`、結果は[新版クリーニング報告](cleaning-report-v2.md)に保存した。通常の回帰用データとsurveyのドメインは対象者ID・全変数が一致した。ステップ1では不満割合・回帰を計算せず、その後ステップ2で通常の回帰を実行・検証した。

## 4. 回帰と表示する結果

通常の回帰は、2つのモデルを別々に実行する。

```r
glm(life_dissatisfied ~ frequency_group, data = S, family = binomial())
glm(life_dissatisfied ~ quantity_group, data = S, family = binomial())
```

surveyでも、同じ対象者S・カテゴリ・参照水準・式を使う。

```r
svyglm(life_dissatisfied ~ frequency_group,
       design = design_S, family = quasibinomial())
svyglm(life_dissatisfied ~ quantity_group,
       design = design_S, family = quasibinomial())
```

1つのカテゴリ変数だけを使うため、予測不満割合は、通常の回帰ではそのカテゴリの単純な不満割合、surveyでは調査重みを使った不満割合に対応する。調整後の割合とは呼ばない。回帰から求めた割合を、それぞれの単純集計・重み付き集計と照合する。

主に示すのは各カテゴリの不満割合（%）、非飲酒カテゴリとの差（パーセントポイント）、それぞれの95%信頼区間。頻度と量の図を1枚ずつ作り、通常の回帰とsurveyの点と区間を並べる。カテゴリの中間点を実際の値と見なして連続曲線を描かない。割合と差の表示は小数1桁、内部計算は丸めない。

オッズ比や個別のp値を記事の中心にしない。区間は各推定値の点ごとの区間で、全比較を同時に保証する区間ではない。有意な組み合わせだけを選ばず、予定した全カテゴリを同じ図表で示す。

### 4.1 不確実性の計算

予測割合はロジット尺度で係数と共分散から区間を求め、確率へ戻す。割合の差はデルタ法で共分散を含め、2群の予測値を独立として分散を足さない。

通常の回帰は`vcov(glm)`と正規分布によるモデルベースの区間、surveyは`vcov(svyglm)`と解析ドメインの`degf`によるt分布で設計ベースの区間を求める。背景変数の調整がないので、予測周辺平均や`svypredmeans`は使わない。

quasibinomialという指定だけで調査設計が反映されるわけではない。重み・層・PSUはdesignで指定する。二値応答ではsurveyのbinomialとquasibinomialの点推定と設計ベースの標準誤差は同じである。[survey公式説明](https://r-survey.r-forge.r-project.org/pkgdown/docs/reference/svyglm.html)

## 5. 調査設計とファイルの扱い

採用州・版・元重みは`config/module_sources.csv`に固定する。主ファイルは_LLCPWT、V1は_LCPWTV1、V2は_LCPWTV2、V3は_LCPWTV3を使う。MarylandのV1・V3、MichiganとNew YorkのV1・V2は、飲酒や欠測で絞る前の州・版別の全レコード数の比率を元重みに掛ける。

層は_STATEと_STSTR、PSUは_STATEと_PSUの組み合わせとし、層へのネストを指定する。有限母集団補正は指定しない。全対象の調査設計を作り、後からSを`subset`で指定する。`survey.lonely.psu="adjust"`、`survey.adjust.domain.lonely=TRUE`を使う。全体は1,475層で単独PSUの層は61。新版ドメインの非空層は1,397、1PSUだけになる層は25、設計自由度は253,771。質問票版を別の抽出層と決めつけない。

公開ページと主XPTの列数・更新表記の差は[旧クリーニング報告](cleaning-report.md)に保持する。追加した量の変数も版間で照合済みである。元ZIPは変更せず、URL・取得日時・SHA-256で使用ファイルを特定する。同じ更新版に統一できたとは主張しない。

## 6. この分析で言えること

単純なモデルなので、飲酒カテゴリが異なる人たちの実際の差を示す。年齢・性別・所得・州などの構成の違いも含む。量と頻度を別々に分析するため、頻度を一定にした量の関連、量を一定にした頻度の関連は示さない。

surveyは調査の抽出方法を扱うものであり、群間の背景の違いを交絡として自動調整するものではない。重みは割合を集計する構成、層・PSUは不確実性の計算に影響する。通常の回帰とsurveyの差を、どれか1つの原因へ定量的に分解したとは説明しない。

「過去30日に飲酒なし」は生涯非飲酒・禁酒・以前は飲んでいた人を区別できない。横断調査なので、個人の生活満足度の変化や飲酒・禁酒の効果は判断できない。逆方向の関連、背景の違い、自己申告の誤差、欠測者の選択は残る。全米・日本の成人の代表値とは扱わない。

重回帰は主分析に含めない。将来、背景をそろえた差を別の問いとして分析する場合は、背景の定義・欠測条件を改めて決め、同じ対象者で単純なモデルを再計算してから調整による違いを比較する。
