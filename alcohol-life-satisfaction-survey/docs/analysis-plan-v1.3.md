## 1. 分析する問い

> 飲酒と生活満足度の関連を通常のRの回帰で計算した場合と、surveyで調査設計を考慮した場合では、推定値や信頼区間がどう変わるか。

分析する関連は、過去30日に飲酒した成人の中での、一度の多量飲酒の有無と生活への不満の割合。記事ではこの題材を使い、公開調査データの分析で重み・層化・抽出単位を扱う意味を説明する。

禁酒の推奨や飲酒の正当化を先に結論とせず、差の方向にかかわらず同じ基準で報告する。先行研究の直接の再現や新規性を主張する研究ではなく、公開データに向き合い、再現可能な分析過程を示す教育的な分析とする。先行研究の調査メモ（非公開の作業メモ）

## 2. 設計の要点

| 項目 | 固定する内容 |
|---|---|
| データ | BRFSS 2023 |
| 対象 | 生活満足度のモジュールを実施した州・DCの、過去30日に飲酒した18歳以上の成人 |
| 比較 | 一度の多量飲酒が1回以上ある人と、0回の人 |
| 評価項目 | 生活に「不満・非常に不満」と回答した割合 |
| 分析 | 通常の`glm`と、重み・層化・PSUを反映した`svyglm`。対象者と説明変数は同じ |
| 主に示す結果 | 各方法の群別予測不満割合、群間差（パーセントポイント）、95%信頼区間 |

生活満足度は`LSATISFY`を使用し、1=非常に満足・2=満足をY=0、3=不満・4=非常に不満をY=1とする。7・9・空欄は欠測。4段階の分布も同じ評価項目の内訳として表示するが、別の評価項目や別の主比較は設けない。1～4を等間隔の数値として平均しない。

## 3. 分析の手順と図表

1. **対象者を確定する。** 対象地域・版を採用し、重みを合わせて調査設計を定義した後、現在飲酒者に限定する。飲酒分類、生活満足度、調整変数がすべて有効な完全ケースをSとし、2つの回帰で同じSを使う。除外理由・人数・欠測割合を記録する。
2. **通常のRの回帰を行う。** `glm`で生活への不満を目的変数とするロジスティック回帰を行う。多量飲酒の有無、年齢・性別・地域・教育・所得・婚姻・人種／民族・喫煙・飲酒頻度を説明変数とし、調査重み・層化・PSUは使わない。比較用の分析であり、BRFSSの人口推定の最終結果としては扱わない。
3. **surveyで同じ回帰式を使う。** `svyglm`に置き換え、対応する調査重み・層化・PSUを反映する。重みの違いと分散推定の違いを説明し、こちらをBRFSSの調査設計に沿った分析として報告する。

記事の図表は、対象者数と背景の表、2群の生活満足度4段階の重み付き分布図、通常の回帰とsurveyの結果を並べた表にまとめる。結果表には各方法の群別予測不満割合・差・95%信頼区間を載せ、割合と差は小数1桁で表示する。回帰出力を説明するときは多量飲酒の係数と標準誤差に絞る。内部計算は丸めない。

## 4. Rでの推定方法

通常の回帰は`glm(..., family = binomial())`、surveyの回帰は`svyglm(..., design = ..., family = quasibinomial())`を使う。二値応答ではsurveyのbinomialとquasibinomialの点推定・設計ベースの標準誤差は同じであり、familyの名称の違いを調査設計による差の原因として扱わない。quasibinomialの指定自体が層化やPSUを考慮するわけではない。[svyglmの公式説明](https://r-survey.r-forge.r-project.org/pkgdown/docs/reference/svyglm.html)

Bは多量飲酒の有無、Cは付録Cの背景属性、Dは飲酒頻度とする。両方の回帰式をB + C + f(D)に固定し、カテゴリの参照水準もそろえる。f(D)の表現も付録Cで事前に固定する。変数選択や多数のモデル比較は行わない。

Sの各人のC・Dを保ち、全員のBを0または1に設定して予測する。通常の回帰では各人を同じ重さで平均し、surveyでは調査重みWで平均する。前者の標準化先はSの回答者構成、後者はSの重み付き構成なので、両者は同じ人口構成への推定ではない。この違いも記事で明示する。

通常の回帰の予測不満割合P_glm(b) = Σ[i∈S] p̂_glm(B=b, C(i), D(i)) / |S|

surveyの予測不満割合P_svy(b) = Σ[i∈S] W(i) × p̂_svy(B=b, C(i), D(i)) / Σ[i∈S] W(i)

各方法の群間差Δ_m = 100 × {P_m(1) − P_m(0)}（パーセントポイント）

正の差は、多量飲酒ありの群の不満割合が高いことを表す。これは回帰による標準化であり、飲酒行動を変えた場合の効果とは解釈しない。オッズ比を主な報告値にしない。

通常の回帰は、Sの背景を固定した予測平均と群間差について、`vcov(glm)`とデルタ法によるモデルベースの標準誤差・正規分布による95%信頼区間を求める。群間差の勾配は2つの予測平均の勾配の差とし、共分散を含める。これは調査設計を反映しない比較用の区間である。

surveyでは`svypredmeans`で予測周辺平均と共分散を求め、`svycontrast`で差を計算する。APIにはBを除いた調整モデルを渡し、groupfactorでBを指定する。2群の予測値を独立として標準誤差を足さない。差の95%信頼区間は共分散を含む設計ベースの分散と、解析ドメインの`degf`によるt分布を使う。各方法の予測割合の区間はロジットスケールで求めて元に戻す。[予測周辺平均の公式説明](https://r-survey.r-forge.r-project.org/pkgdown/docs/reference/svypredmeans.html)

重みは回帰係数と予測を平均する人口構成に影響し、層化・PSUの情報は分散推定に影響する。通常の回帰とsurveyの2つだけの比較では、全体の差を個々の要因に定量的に分解できない。また、信頼区間の差にはモデルベースと設計ベースの分散推定、参照する正規分布とt分布の違いも含まれる。単一の原因だけで差を説明しない。

## 5. 記事の切り口と構成

タイトル案：**飲酒と生活満足度をRで回帰分析する：glmとsurveyで何が変わる？**

1. **まず普通に回帰してみる。** 飲酒と生活満足度の関連を知りたいという動機、評価項目と対象の定義、通常の`glm`のコードと結果を示す。
2. **データの集め方を確認する。** BRFSSの回答者を等しい重さで扱った結果が、調査対象人口の推定に直結しない理由を説明する。重みと、層化・抽出単位の役割を区別する。
3. **surveyで計算し直す。** 同じ対象者と回帰式を使い、追加した調査設計の指定と結果を示す。
4. **推定値と信頼区間を並べて読む。** 不満割合の差と不確かさがどの程度変わったかを報告し、今回のデータで言える範囲を説明する。

結論の逆転、有意差の出現、信頼区間の拡大を記事の成立条件にしない。ほとんど同じ結果なら、どの部分が近かったかをそのまま示す。有意・非有意の切り替わりだけで解釈を逆転させない。データやモデルを変更して見栄えのする差を探さない。

## 6. 結果の読み方

推定するのは、対象地域の現在飲酒者のうち、必要な項目に回答した集団における関連である。任意モジュールの実施地域と完全ケースに範囲が限られるため、全米の成人や日本人の代表値とは扱わない。

横断調査なので、飲酒と生活満足度の時間順序、逆方向の関連、未測定の背景は判別できない。「禁酒すると満足度が上がる」とは結論づけない。現在飲酒者に限定しても健康状態による飲酒の選択は残り、重みも今回の項目欠測を自動的に補正するものではない。

自己申告の測定誤差やモデルの関数形への依存も限界として示す。信頼区間が0をまたぐことを「関係がない」と断定せず、差の大きさと区間の幅を説明する。不満割合の差を健康被害や改善人数へ換算しない。

### A. 対象地域・質問票版・重み

### A.1 推論の範囲

BRFSSは施設入所者を除く成人を対象とする州単位の電話調査である。今回の予定対象は、公式のモジュール実施一覧に基づく39州とDC。Puerto Ricoは今回の地理的範囲から除く。これは結果を見る前の範囲指定であり、結果に応じて地域を追加・削除しない。

人口規模を反映して対象地域を合わせた推定を行う。各州を同じ重さで平均する分析にはしない。対象地域の選定は任意モジュールの実施によるため、重みを使っても未実施州や日本の成人へ自動的に一般化できない。項目欠測による対象者の選択も別に残る。[BRFSSの調査・重みの説明](https://www.cdc.gov/brfss/annual_data/2023/pdf/Complex-Sampling-Weights-and-Preparing-Module-Data-for-Analysis-2023-508.pdf)

### A.3 同一州で複数の版を併用する場合

MarylandはV1・V3、MichiganとNew YorkはV1・V2を併用する。版別の元の重みをそのまま足すと同じ州の人口を重複して表すため、CDCの手順に沿って調整する。

- 州s、使用する版vの調査レコード数をn(s,v)とする。
- 比率q(s,v) = n(s,v) / 使用する全版のn(s,v)の合計を求める。
- 最終重みW(s,v) = 元の版別重み × q(s,v)とする。
- n(s,v)は飲酒者・完全ケースに絞る前の、その州・版の調査レコード数で求める。生活満足度への回答者数で計算しない。
- 単一の版だけを使用する州とLLCP2023から採用する州の重みは変更しない。
- 2版だから一律0.5とせず、実際の比率を使う。全州の重みを州ごとに合計1へ正規化しない。

基礎資料は[CDCのモジュールデータ準備手順、複数版を合わせる例](https://www.cdc.gov/brfss/annual_data/2023/pdf/Complex-Sampling-Weights-and-Preparing-Module-Data-for-Analysis-2023-508.pdf)。同資料の例には版名・コードの表記揺れがあるため、採用する州と版の対応はモジュール実施一覧を優先する。

### B. 飲酒習慣の定義

| 項目 | 変数 | 分析用の定義 |
|---|---|---|
| 過去30日の飲酒 | `ALCDAY4` | 有効な飲酒頻度の回答がある人を現在飲酒者、888を「過去30日に飲酒なし」とする |
| 飲酒頻度D | `ALCDAY4` | 101～107は週の日数×30/7、201～230は月の日数。30日当たりの日数に統一し、変換時に丸めない |
| 一度の多量飲酒B | `DRNK3GE5` | 現在飲酒者で1～76ならB=1、88ならB=0。77・99・空欄は欠測 |
| 多量飲酒の質問の基準 | 質問票Core Section 12 | 男性は1回5ドリンク以上、女性は4ドリンク以上 |

上記は[公式質問票](https://www.cdc.gov/brfss/questionnaires/pdf-ques/2023-BRFSS-Questionnaire-508.pdf)、[コードブック](https://www.cdc.gov/brfss/annual_data/2023/zip/codebook23_llcp-v2-508.zip)、[算出変数の仕様](https://www.cdc.gov/brfss/annual_data/2023/pdf/2023-calculated-variables-version4-508.pdf)に基づく。週回答と月回答を混同せず、777・888・999を日数に変換しない。通常の飲酒頻度の有効範囲は週1～7日・月1～30日とする。

注意事項：

- `DRNK3GE5`は回数であり、日数ではない。同じ日に複数回があり得るため、30回を超えることや飲酒日数より多いことだけを理由に除外しない。
- `_RFBING6`の「なし」には非飲酒者も含まれる。主比較では現在飲酒者を先に定義し、`DRNK3GE5`から分類する。算出変数は整合性の点検に使う。
- `ALCDAY4=888`で多量飲酒回数も空欄なら、飲酒なしによる正常な質問スキップとして扱う。現在飲酒者の空欄を0回に置き換えない。
- 飲酒なしと正の多量飲酒回数が同時に記録されるなど、定義が矛盾する回答は飲酒分類不能とし、件数を報告する。都合のよい方を採らない。
- 「過去30日に飲酒なし」を「禁酒群」「生涯非飲酒者」と呼ばない。元飲酒者との区別はできない。
- ドリンクはBRFSSの質問票上の単位を指す。日本のグラス数・日本酒の合数と同一視しない。

分析対象は現在飲酒者のB0=多量飲酒なし、B1=多量飲酒ありの2群。比較はB1対B0の1つだけとする。

### D. surveyで表現する調査設計

調査重みは対象人口の構成を反映するために使い、回帰の調整変数は群間の背景の違いを考慮するために使う。役割を分けて説明する。

設計オブジェクトの仕様：

- 重み：A.3で定義した正の有限値の最終重みW。
- 層：`_STATE`と`_STSTR`の組み合わせ。
- PSU：`_STATE`と`_PSU`の組み合わせ。層へのネストを指定する。
- 有限母集団補正：必要な情報がないため指定しない。
- 分散：層化・PSUを考慮したTaylor線形化を用いる。
- 単独PSUの層：`survey.lonely.psu="adjust"`、`survey.adjust.domain.lonely=TRUE`を固定し、該当層数を記録する。無条件に確実抽出とみなして分散を0にしない。

対象地域・質問票版を採用し、重みを合わせた全レコードで`svydesign`を定義する。その後、現在飲酒者や完全ケースを`subset`によるドメインとして指定する。飲酒者や完全ケースだけの通常データフレームを先に作り、そこから調査設計を再定義しない。質問票版を新たな抽出層と決めつけることも避ける。

重複点検のキーは`_STATE`と`SEQNO`。主ファイルと版別ファイルに同じ回答者がいる可能性があるため、州ごとの採用元をA.2に限定する。予期しない重複があれば、採用元を点検して解決し、単に先頭行を残す処理はしない。

重み・層・PSUの基本仕様は[CDCの資料](https://www.cdc.gov/brfss/annual_data/2023/pdf/Complex-Sampling-Weights-and-Preparing-Module-Data-for-Analysis-2023-508.pdf)、ドメイン推定と単独PSUの扱いは[surveyの公式説明](https://r-survey.r-forge.r-project.org/survey/exmample-lonely.html)を参照する。CDC資料のR例にある`id=~1`をそのまま転記せず、本文で指定されている公開PSU変数を明示して使う。
